## Envelope shapes differ

`devices` and `device-groups` return a full paging envelope. `blueprints` returns
only `results` + `totalCount` — no `hasNext`. A generic paging helper must not
assume `hasNext` exists.

## These endpoints are cross-platform

`devices` and `device-groups` span macOS and iOS/iPadOS in a single list —
`device-groups` mixes `COMPUTER` and `MOBILE` `deviceType` values, smart and
static. They are **not** equivalent to the Jamf Pro API's separate computer and
mobile-device endpoints, so a tool ported from `listComputers` semantics will
silently include mobile devices.
